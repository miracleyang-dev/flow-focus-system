# 心流 (Flow) - 个人效率系统

一个极简高效的个人专注力与效率管理应用。基于原生 Web 技术与 Node.js 构建，支持 PWA，覆盖任务、习惯、时间安排与回顾总结，帮助你快速进入“心流”。

## 核心特性

- **今日总览**：进度环、待办/完成统计、今日任务、时间安排、习惯打卡一屏聚合
- **任务管理**：四象限优先级、拖拽排序、标签筛选、子任务、截止日期/时间、循环任务
- **时间安排**：为当天添加时间块，支持类别（日常/娱乐）与绑定任务/习惯
- **习惯系统**：时长/次数两种记录方式与打卡日志
- **回顾总结**：近 7 天统计 + 周视图任务分布；AI 生成总结（1-90 天范围可选）并可下载
- **AI 辅助**：倒空大脑一键拆解任务、总结洞察、模型连通性测试
- **PWA**：可安装到桌面/移动端，离线可用

## 功能视图

| 视图 | 说明 |
|------|------|
| 今日 | 进度概览、今日任务、时间安排、习惯打卡 |
| 任务 | 倒空大脑、快速添加、四象限任务看板、拖拽排序、标签筛选 |
| 回顾 | 近 7 天统计、周视图任务分布、AI 总结与下载 |
| 设置 | AI 配置、标签管理、导入导出、清空数据 |

## 数据结构

日志保留最近 90 天：

| 数据 | 说明 |
|------|------|
| `tasks` | 任务本体（四象限、标签、日期、时间、时长、循环、子任务等） |
| `taskLogs` | 任务完成记录（用于回顾与总结，90 天保留） |
| `habits` | 习惯本体（时长/次数、图标） |
| `habitLogs` | 习惯打卡记录（90 天保留） |
| `timeBlocks` | 当日时间块（类别或绑定任务/习惯） |
| `tags` | 标签与颜色 |

## 每日刷新机制

- 零点自动刷新：定时刷新 + `visibilitychange` 兜底
- 手动刷新：今日视图右上角按钮
- 刷新内容：循环任务推进、清理过期已完成任务、清理超过 90 天日志

## 技术栈

- **前端**: HTML5 + CSS3 + 原生 JavaScript（无框架）
- **后端**: Node.js 原生 `http` 模块
- **存储**: Railway Redis（云端持久化）+ localStorage（本地缓存与离线兜底）
- **PWA**: Service Worker + manifest.json

## 快速开始

```bash
npm install
npm start
# 访问 http://localhost:3000
```

应用通过 `/api/data` 读写 Railway Redis，浏览器同时保留 localStorage 缓存。Railway 部署需要配置 `REDIS_URL`、`REDIS_PRIVATE_URL` 或 `REDIS_PUBLIC_URL` 其中一个环境变量；未配置时应用仍可离线使用，但不会有云端持久化。
